id=\"doxcnRXpX9inMmJbH8SUqONglMf\"><b>这个实验对论文的意义（写论文时必须讲清楚）：</b></p><ol><li id=\"doxcnUwwuXKjE2urnqsVSoa1vYQ\" seq=\"1\" seq-marker=\"1. \"><b>证明 coverage guarantee 是模型无关的。</b>共形预测的有限样本覆盖保证来自 finite-sample 统计保证，这把论文的适用范围从\"云端大模型\"扩展到\"边缘本地模型\"，是 WWW 审稿人看重的 deployment story。</li><li id=\"doxcn0ctlDGGZUkKry2S6INDAPb\" seq-marker=\"4. \"><b>与 R13（SetFit 混合路由）形成呼应。</b>小模型实验 + 混合路由实验一起回答：\"为什么不直接用小模型+混合路由？\"答案是：小模型+混合路由省了 API 调用但没有 coverage guarantee；我们的方法即使在 7B 上仍然有统计保证。</li></ol><p id=\"doxcnSxHoWRW9GTaMwxjWJgCHnb\"><b>时间点：</b>主表（CLINC150/MixATIS/MixSNIPS + id=\"doxcnFzW1xqbrj5TjsnBgfE2pKg\"><b>参考论文：</b>TECP: Token-Entropy Conformal Prediction for LLMs（arXiv 2509.00461）。核心思想：对同一 query 用 temperature&gt;0 采样 LLM T 次，统计 main intent 的预测分布熵作为 epistemic [\"intent1\",\"intent2\",...]</code>。</li><li id=\"doxcnQtJTTGcMvUE26lktl1PUwc\" seq-marker=\"3. \">新建 <code>scripts/11_eval_tecp.py</code>：对每条样本，统计 5 次采样中 main intent 的频率分布 p(y)，算 entropy <code>H = -Σ p(y) log p(y)</code>；calib 集上取分位数作为阈值 θ；test 集上 entropy &gt; θ 则 reject，否则取 argmax。</li><li id=\"doxcnp72r4mvQTlNceGpU0LC7le\" seq-marker=\"4. \">对比指标：和我们的方法在同一 test 子集上比 (a) Main Macro-F1，(b) OOS tradeoff 图放论文 Figure 4。</p><p id=\"doxcn8mJLu1z4OtSkjl7fUIIeig\"><b>时间估计：</b>脚本 0.5 天，500 条采样 ~2 小时跑通，3 天出结果。</p><h3 id=\"doxcnuzKJLYrRP3zoDuocMjrjkg\">子任务 R13：SetFit + MC Dropout 混合路由（参考论文 +
