      "content": "<fragment mode=\"section\" requested-start=\"doxcnEHqhiedE60jlqhQe79zm0g\"><h2 id=\"doxcnEHqhiedE60jlqhQe79zm0g\">基线与配置</h2><p id=\"doxcnnx0bjNB4XNM3EpXlftwhbE\">结合实际实验路径（免训练为主，无 GPU 训练条件），基线按\"是否做共形校准\"组织，而非\"LLM vs 判别式\"。核心论点：零训练 LLM 已能做意图识别但 overconfident，本文贡献是给它加上带 coverage 保证的集合级校准与拒识。R1–R5 全部直接复用已有 predictions（无需再调 LLM API）；R6–R8 为消融，改 config/重跑 calib 阈值即可。</p><h3 id=\"doxcnZh3IScr05b0rFstO4ATnUf\">Plan-Extra：低参数量模型上的鲁棒性验证</h3><p id=\"doxcnIeyTeAUpJcGJucYcFnPlrc\"><b>实验设置：</b>用 DashScope 上的 Qwen2.5-7B-Instruct（或 Llama-3.1-8B）替换 qwen3.7-plus，保持相同 prompt、相同检索索引、相同共形 pipeline，在 CLINC150 上重跑 calib+test。预期 Main Macro-F1 从 0.896 降到 ~0.75-0.80。</p><p id=\"doxcnRXpX9inMmJbH8SUqONglMf\"><b>这个实验对论文的意义（写论文时必须讲清楚）：</b></p><ol><li id=\"doxcnUwwuXKjE2urnqsVSoa1vYQ\" seq=\"1\" seq-marker=\"1. \"><b>证明 coverage guarantee 是模型无关的。</b>共形预测的有限样本覆盖保证来自 exchangeability，不依赖 f_LLM 的准确率。无论 backbone 是 70B API 还是 7B 本地模型，calib 集上分位数取到的阈值都保证 test 集 coverage ≥ 1-α。这是我们方法的理论卖点——它把\"模型能力差异\"转化为\"预测集大小/拒识率差异\"，而不是破坏覆盖保证。</li><li id=\"doxcnNms5ifyd8Y7gqo7kJHBfBh\" seq-marker=\"2. \"><b>展示 error-coverage tradeoff 曲线的形态。</b>小模型 baseline accuracy 低，共形校准会自动输出更大的候选集、更多 clarify/reject 决策，但 coverage 仍然达标。这张图（横轴 alpha，纵轴 empirical coverage，多条曲线对应不同模型规模）直接回应审稿人\"你是不是只在强模型上 cherry-pick\"的质疑。</li><li id=\"doxcnC0Aqg511rDCyqh32jq8epg\" seq-marker=\"3. \"><b>工程落地价值。</b>很多真实场景不能调用商用大模型 API（数据隐私、延迟、成本），必须本地部署 7B。我们的方法在小模型上仍然提供 finite-sample 统计保证，这把论文的适用范围从\"云端大模型\"扩展到\"边缘本地模型\"，是 WWW 审稿人看重的 deployment story。</li><li id=\"doxcn0ctlDGGZUkKry2S6INDAPb\" seq-marker=\"4. \"><b>与 R13（SetFit 混合路由）形成呼应。</b>小模型实验 + 混合路由实验一起回答：\"为什么不直接用小模型+混合路由？\"答案是：小模型+混合路由省了 API 调用但没有 coverage guarantee；我们的方法即使在 7B 上仍然有统计保证。</li></ol><p id=\"doxcnSxHoWRW9GTaMwxjWJgCHnb\"><b>时间点：</b>主表（CLINC150/MixATIS/MixSNIPS + R9/R10/R12）出来后再跑，不阻塞投稿。若算力紧张，只在 CLINC150 上做一个 7B 点即可。</p><h3 id=\"doxcnv4qIiafsZLENVxcbLTwbBe\">子任务 R11：TECP-style Token Entropy 共形（参考论文 + 实现）</h3><p id=\"doxcnFzW1xqbrj5TjsnBgfE2pKg\"><b>参考论文：</b>TECP: Token-Entropy Conformal Prediction for LLMs（arXiv 2509.00461）。核心思想：对同一 query 用 temperature&gt;0 采样 LLM T 次，统计 main intent 的预测分布熵作为 epistemic uncertainty，再做 split conformal。</p><p id=\"doxcnSt9N6DSAp7jTMeumgwIc6e\"><b>具体步骤：</b></p><ol><li id=\"doxcnsZnZHwc1E0MPK08BN3H365\" seq=\"1\" seq-marker=\"1. \">新建 <code>scripts/11_run_llm_samples.py</code>，基于现有 <code>03_run_llm.py</code>，把 <code>llm.classify_intent()</code> 调用包成循环：temperature=0.7，采样 T=5 次，输出 5 个 llm_main 列表。</li><li id=\"doxcn1Zj2ww1QembFjjocWDpBjf\" seq-marker=\"2. \">先在 CLINC150 test 上跑 500 条子样本（<code>--limit 500</code>），确认 API 配额够用。输出格式：每条 record 加字段 <code>\"samples\": [\"intent1\",\"intent2\",...]</code>。</li><li id=\"doxcnQtJTTGcMvUE26lktl1PUwc\" seq-marker=\"3. \">新建 <code>scripts/11_eval_tecp.py</code>：对每条样本，统计 5 次采样中 main intent 的频率分布 p(y)，算 entropy <code>H = -Σ p(y) log p(y)</code>；calib 集上取分位数作为阈值 θ；test 集上 entropy &gt; θ 则 reject，否则取 argmax。</li><li id=\"doxcnp72r4mvQTlNceGpU0LC7le\" seq-marker=\"4. \">对比指标：和我们的方法在同一 test 子集上比 (a) Main Macro-F1，(b) OOS AUROC，(c) avg 调用成本（5× vs 1×），(d) coverage at α=0.1。</li></ol><p id=\"doxcnloxOnQcrYlRO7nPeDI85oe\"><b>预期结论：</b>TECP 的 entropy 准确率可能略高，但 5× API 成本；我们单次调用 + 检索融合在 coverage 相当的情况下成本 1/5。这张 cost-accuracy tradeoff 图放论文 Figure 4。</p><p id=\"doxcn8mJLu1z4OtSkjl7fUIIeig\"><b>时间估计：</b>脚本 0.5 天，500 条采样 ~2 小时跑通，3 天出结果。</p><h3 id=\"doxcnuzKJLYrRP3zoDuocMjrjkg\">子任务 R13：SetFit + MC Dropout 混合路由（参考论文 + setfit open-autonlu</code>（open-autonlu 内置 SetFit + MSP/Mahalanobis OOD detection）。</p><p id=\"doxcnkvBD9TjSyRdheEJsmibDTg\"><b>具体步骤：</b></p><ol><li id=\"doxcnj9bxT41NVx7kSh4MkJnF1d\" seq=\"1\" seq-marker=\"1. \">环境：<code>pip install setfit open-autonlu datasets</code>，不需要 GPU（CPU 即可，SetFit few-shot 训练很快）。</li><li id=\"doxcnrhzJA3R443ctQJgQpu4HIe\" seq-marker=\"2. \">数据：用现有 <code>setfit_doc/en/zero_shot.ipynb</code>。</li><li id=\"doxcnHbqNAoAKGjJtikIevMqyOg\" seq-marker=\"4. \">MC Dropout 推理：把 model 设为 <code>model.model_body.eval()</code> 但打开 dropout（<code>for m in model.modules(): if isinstance(m, nn.Dropout): m.train()</code>），对每条 test 样本前向 T=30 次，收集 30 个预测分布，算 predictive entropy 和 mutual information。</li><li id=\"doxcnJOeSNFkTClwEFlSdq57mPe\" seq-marker=\"5. \">OOS 检测：用 open-autonlu 的 <code>OodMethod.MSP_OOD</code> 或 Mahalanobis 距离，在 calib 集上定 FPR=0.05 阈值。</li><li id=\"doxcnBAWfN7kwFVArLIZ3OtU4ag\" seq-marker=\"6. \">混合路由决策：entropy 小于阈值 tau 时直接用 SetFit 结果（省 LLM）；entropy 大于等于 tau 或 OOS 时 fallback 到我们的 LLM + 共形校准。统计 LLM 调用率（fallback 比例）和整体准确率。</li></ol><p id=\"doxcnEnvZ40wsG6Ft421KlEuMih\"><b>对比指标：</b>(a) 端到端 Main F1，(b) LLM API 调用比例（越低越好），(c) OOS
