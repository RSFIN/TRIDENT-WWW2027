href=\"https://trec.nist.gov/data/cast2022.html\">[15]</a>；Needle in the Web 的 663 条模糊探索式查询上，多数 Agent 准确率低于 35%<a href=\"https://arxiv.org/abs/2512.16553\">[16]</a>；VibeSearchBench 中最佳模型 F1 仅 30.30<a href=\"https://arxiv.org/abs/2605.27882\">[8]</a>。在必须单轮响应的入口（搜索框、IM 机器人、Agent 冷启动），系统必须一次给出\"有序意图集\"，并对不确定输入做出可信决策。</p><p><b>差距：</b>现有三类方法都未同时覆盖单轮多意图与可信拒识。Prism 依赖多轮澄清与自演进微调，不适配没有澄清机会的单轮入口<a href=\"https://arxiv.org/abs/2601.08653\">[6]</a>；DoorDash 借助电商目录实体与商品检索做 grounding，不面向通用查询<a href=\"https://arxiv.org/abs/2603.01486\">[7]</a>；QP-OneModel 用统一生成式输出意图描述，但未给出可保证的拒识/澄清触发决策<a href=\"https://arxiv.org/abs/2602.09901\">[12]</a>。与此同时，意图理解的\"可信度\"维度（OOS 拒识、置信度校准、误拒成本）在 Web 场景缺少系统研究——OOS 检测的 hard-negative 脆弱性已被反复证实（Banking77 上 AUROC 由 0.964 降至 0.810）<a href=\"https://arxiv.org/abs/2403.05640\">[20]</a><a href=\"https://arxiv.org/abs/2101.03778\">[21]</a><a href=\"https://xdbdilab.feishu.cn/docx/Xg9MdxNOFoAhQWxiAjnc1wEynXd\">[17]</a>。</p><p><b>定位与贡献：</b>我们提出面向 Web 查询入口的单轮意图理解框架：免训练知识库索引＋检索增强推理输出\"主意图＋有序次意图集\"，校准模块提供可靠不确定性，三态决策决定放行、澄清还是拒识。三条贡献：(1) 首个将\"多意图集输出\"与\"校准拒识\"一体化的单轮框架，与上述三点差异化；(2) 全公开数据的三组评测协议与 L1–L6 指标子集，可直接复现；(3) 算法贡献：检索-grounded 无分类器集合级共形校准——把共形从\"单点/固定标签集覆盖\"扩展到\"变长多意图集 Jaccard 覆盖\"，配合自适应最小澄清集；(4) 工程证据：免训练路线在\"零训练部署×知识可更新×精度×校准\"上的表现，轻微调（LoRA/SetFit）对照量化轻量训练增益。</p><h1>相关工作（Related Work 组织）</h1><p>以下五条线构成本文的 Related Work，每条给出代表工作与本文差异，组织为\"综述一句话＋差异一句话\"。总览见表 意图/10 域、含原生 OOS）、Banking77、HWU64 仍是评测事实标准<a href=\"https://xdbdilab.feishu.cn/docx/Xg9MdxNOFoAhQWxiAjnc1wEynXd\">[17]</a>。2025–2026 年新基准把难度推高：IntentGrasp 将意图理解统一为多选问答，20 个前沿模型在高难度 Gem Set 上 F1 全部低于 25%、17/20 低于随机基线（15.2%），人类基线 81.1%<a href=\"https://arxiv.org/html/2605.06832v1\">[10]</a>；ConsintBench 在 20 万+ 条真实消费讨论上评测 20 个模型，最强模型在深层意图理解上仍不足<a href=\"https://arxiv.org/html/2510.13499v2\">[11]</a>。结论：意图理解远未饱和，评测正从\"分得准\"走向\"理解深、拒得对\"。本文承接该趋势，把\"多意图集＋拒识\"作为可评测的能力维度。</p><h2>多意图与组合意图理解</h2><p>MixATIS/MixSNIPS 首次把 ATIS/SNIPS 拼出 1–3 意图混合查询（比例约 3:5:2）<a href=\"https://github.com/LooperXX/AGIF\">[13]</a>；MultiSNIPS 等进一步建模意图共现关系<a href=\"https://arxiv.org/html/2602.08322v2\">[14]</a>；生成式多意图检测把任务建模为多标签输出。本文差异：现有工作聚焦\"预测得准\"，本文把多意图集输出与\"校准后的拒识决策\"绑定，除 Hit@k/意图集 IoU 外还评测\"何时该拒\"。</p><h2>OOS 检测与不确定性校准</h2><p>判别式 OOS 强基线仍是 Mahalanobis 距离（CLINC150 上 AUROC 98.4、FPR95 6.8）<a href=\"https://arxiv.org/abs/2101.03778\">[21]</a>；DROID 双表示在 CLINC150 上 Unknown 95.88%<a href=\"https://arxiv.org/html/2510.14110v1\">[19]</a>；但 hard-negative OOS 使 AUROC 显著下降<a href=\"https://arxiv.org/abs/2403.05640\">[20]</a>，多党派对话场景 F1-OOS 仅 45.00 且人类基线仍更高<a href=\"https://arxiv.org/html/2507.22289v1\">[22]</a>。校准方向，温度缩放与共形预测可提供带覆盖保证的候选集<a href=\"https://xdbdilab.feishu.cn/docx/Xg9MdxNOFoAhQWxiAjnc1wEynXd\">[17]</a>。本文差异：把校准与拒识接入三态决策，并在公开模糊查询源上评测\"拒识→澄清触发\"的决策质量。</p><p><b>共形预测与 LLM 不确定性校准的最新进展。</b>共形预测（CP）近年从判别式分类器快速扩展到黑盒 LLM。CICC <a href=\"https://arxiv.org/abs/2403.18973\">[31]</a> 最早把 CP 用于意图识别，在 BERT 分类器上构造带覆盖保证的澄清集并扩展到 OOS，但它绑定判别式 backbone，不处理 LLM-native 场景。UniCR <a href=\"https://arxiv.org/abs/2509.01455\">[34]</a> 融合 self-consistency、retrieval compatibility 等多源证据，用 conformal risk control 做 API-only LLM 的拒答，但面向长文本生成、输出单标签拒绝，不做意图集合扩展。TECP <a href=\"https://arxiv.org/abs/2509.00461\">[35]</a> 用 token entropy 作 logit-free nonconformity score 构造预测集，同样面向选择题 QA。MiRD <a href=\"https://arxiv.org/abs/2605.27091\">[36]</a> 在开放域 QA 上做 miscoverage risk decomposition，把错误分解为漏答/错答两类——这与本文四档分层 loss 思想相通，但 MiRD 不处理意图主辅层级。Xie et al. <a href=\"https://yanfeifionazhou.github.io/\">[37]</a> 针对开放集+不平衡分类提出 CP 框架；Learnable Conformal Abstention <a href=\"https://arxiv.org/abs/2502.06884\">[38]</a> 用 RL 动态学阈值。CP for NLP 综述见 <a href=\"https://arxiv.org/abs/2405.01976\">[39]</a>。</p><p><b>本文定位。</b>现有工作要么绑定判别式 backbone（CICC、Mahalanobis、DROID），要么面向单标签选择或长文本 QA（UniCR、TECP、MiRD）。本文是第一个把 <b>stratified set-valued conformal</b> 用于 <b>LLM-native 多意图识别 + dual OOS 拒识</b> 的工作：四档分层 loss 显式区分 main/aux 覆盖，rank 归一化融合检索分与 LLM 置信度，offline split CP 提供 finite-sample coverage 保证。</p><h2>免训练与高效意图分类</h2><p>41 个开源权重模型的系统评测显示指令微调优先于参数规模（Qwen2.5-3B-Instruct 聚合得分 0.632 超过多数 7B 基础模型），SNIPS 已饱和、校准影响不一致<a href=\"https://arxiv.org/html/2607.27421v1\">[18]</a>；混合路由（小模型＋不确定性→LLM）是工业事实标准，可在接近大模型精度下显著降低延迟<a href=\"https://xdbdilab.feishu.cn/docx/Xg9MdxNOFoAhQWxiAjnc1wEynXd\">[17]</a>。在此基础上，检索增强意图分类（REIC）验证了免重训优势[24]，检索式 kNN 分类在低资源语言有效[26]，嵌入近邻是零样本文本分类标准路线[27]。本文据此选\"免训练知识库索引＋检索增强推理＋校准拒识\"为方法主干，纯 LLM、混合路由与轻量微调（LoRA/SetFit）作对照。</p><h2>Web 场景的意图理解</h2><p>Prism 用复杂意图分解＋逻辑澄清序列降低用户认知负荷<a href=\"https://arxiv.org/abs/2601.08653\">[6]</a>；DoorDash 用目录实体检索＋agentic 搜索＋有序多意图集服务长尾查询（长尾 query 90.7%，相对提升 13.0pp）<a href=\"https://arxiv.org/abs/2603.01486\">[7]</a>；QP-OneModel 统一生成式查询理解<a href=\"https://arxiv.org/abs/2602.09901\">[12]</a>；INTENT-AS-A-TOOL 从 Agent 安全侧追踪意图信号<a href=\"https://arxiv.org/abs/2608.27348\">[9]</a>。本文差异：不依赖多轮、不依赖垂直目录，面向通用单轮入口，把\"有序意图集＋可信拒识\"作为产品可落地的最小闭环。</p><h1>方法（形式化定义）</h1><p>问题定义：给定查询 q 与意图空间 I（取自公开数据集的意图标签集），系统输出主意图 ŷ∈I、有序次意图集 Ŝ＝{ŷ₂,…,ŷ_K}，以及不确定性 u；三态决策按阈值 (τ_lo, τ_hi) 决定：u≥τ_hi 放行，τ_lo≤u&lt;τ_hi 触发澄清（返回候选意图集供用户确认），u&lt;τ_lo 拒识（转人工/安全兜底）。与单标签歧义任务不同，此处真实输出本身是变长意图集 Y（一个查询可同时成立多个意图），因此\"覆盖\"的对象不是某个固定标签，而是 Y 与预测意图集 Ŝ 的集合相似度（Jaccard / 对称差）。免训练设定下不存在可输出 logits 的分类器，不确定性由检索证据与 LLM 自评共同构造。</p><p>模块一 意图知识库构建与检索增强推理：知识库＝公开数据集 train 的意图定义＋示例话语（零标注），索引＝意图级原型＋示例级向量；检索 Top-K（K_r 超参）候选送入 LLM 证据上下文，输出\"主意图＋有序次意图集\"；K 与 K_r 均作超参消融。</p><p>模块二（核心贡献 A：检索-grounded 无分类器集合级共形校准）：现有共形意图方法（如 CICC）假设有训练好的分类器输出分数，免训练路线只有检索相似度与 LLM 自报置信，两者均不可靠且相关。本模块构造融合非一致性分数 s(q)＝g(检索分布统计量 [Top-K 相似度、Top1−Top2 margin、与已确认条目距离], LLM 自评)，在校准集上做 split-conformal；风险度量取预测意图集 Ŝ 与真实意图集 Y 的 Jaccard，控制\"集合级错误率\"（对称差超过阈值的概率）在 1−α 以内。这是把共形从\"单点覆盖\"扩展到\"变长意图集集合级覆盖\"，无需任何梯度训练。</p><p>模块三（核心贡献 B：自适应澄清集大小）：澄清不再返回固定 K 个候选，而是在模块二的共形保证下取最小集合——保证 Ŝ 以 ≥1−α 概率覆盖真实意图集 Y 的最小候选意图数。模糊/长尾查询返回 2–3 个候选，明确查询返回 1 个，域外查询返回 0 个（直接拒识）。三态阈值 (τ_lo, τ_hi) 在校准集上按 FPR95 约束下最大化拒识召回标定；拒识保留安全兜底语义。三个模块可独立消融，对应第 5.5 节。</p><p>方法框架如图 1 所示：知识库构建/检索与推理侧解耦——知识库零标注构建、检索与 LLM 推理免训练，轻微调（LoRA/SetFit）仅作对照。与 CICC（单标签、有训练分类器、TODS 场景）的关键差异在模块二/三：无分类器分数、变长多意图集、Web 单轮拒识。模块与消融一一对应。</p><whiteboard token=\"H4ccw4EefhFkULbUnlocGfCxngf\" type=\"mermaid\">flowchart LR\n  Q[查询 q\nWeb 入口 2509.00461）。核心思想：对同一 query 用 temperature&gt;0 采样 LLM T 次，统计 main intent 的预测分布熵作为 epistemic uncertainty，再做 split conformal。</p><p><b>具体步骤：</b></p><ol><li seq=\"1\" seq-marker=\"1. \">新建 <code>scripts/11_run_llm_samples.py</code>，基于现有 <code>03_run_llm.py</code>，把 <code>llm.classify_intent()</code> 调用包成循环：temperature=0.7，采样 T=5 次，输出 5 个 llm_main 列表。</li><li seq-marker=\"2. \">先在 CLINC150 test 上跑 500 条子样本（<code>--limit 500</code>），确认 API 配额够用。输出格式：每条 record 加字段 <code>\"samples\": [\"intent1\",\"intent2\",...]</code>。</li><li seq-marker=\"3. \">新建 <code>scripts/11_eval_tecp.py</code>：对每条样本，统计 5 次采样中 main intent 的频率分布 p(y)，算 entropy <code>H = -Σ p(y) log p(y)</code>；calib 集上取分位数作为阈值 θ；test 集上 entropy &gt; θ 则 reject，否则取 argmax。</li><li seq-marker=\"4. \">对比指标：和我们的方法在同一 test 子集上比 (a) Main Macro-F1，(b) OOS AUROC，(c) avg 调用成本（5× vs 1×），(d) coverage at α=0.1。</li></ol><p><b>预期结论：</b>TECP 的 entropy 准确率可能略高，但 5× API 成本；我们单次调用 + 检索融合在 coverage 相当的情况下成本 1/5。这张 cost-accuracy tradeoff 图放论文 Figure 4。</p><p><b>时间估计：</b>脚本 0.5 天，500 条采样 ~2 小时跑通，3 天出结果。</p><h3>子任务 R13：SetFit + MC Dropout 混合路由（参考论文 + 实现）</h3><p><b>参考论文：</b>\"Intent
