# 统一指标口径规范 v1.0（论文 T2 表对比基准）

> 目的：消除 Ours / CICC / MULACONF / QP-OneModel 四类方法在 T2 对比表中的口径不一致。
> 适用范围：CLINC150（单标签 + OOS）、MixATIS / MixSNIPS（多标签，无 OOS）。
> 原则：**所有指标在"完整意图集合"上计算，reject 视为空集 ∅ 并计入所有指标分母。**

---

## 0. 数据结构约定

| 符号 | 含义 |
|---|---|
| x | 一条测试样本 |
| Y | 真实意图集合（**全部意图**，含主意图；单标签时 \|Y\|=1） |
| P | 系统最终输出的预测意图集合（决策为 reject 时 **P = ∅**；clarify 时 P = 候选集合） |
| R | 意图按置信度降序排列的列表（供 Hit@k 使用；P=∅ 时 R=∅） |
| m | 主意图预测 = P 中置信度最高者（P=∅ 时 m=∅，计为预测错误） |
| N | 全部测试样本数（**含被拒样本**） |

Jaccard 定义：`J(P, Y) = |P ∩ Y| / |P ∪ Y|`（P=Y=∅ 时约定为 1；仅一方为空时 = 0）。

---

## 1. L1 主意图指标（单标签 & 多标签通用）

```
Accuracy  = #{ m == Y 的唯一元素 } / N          # 仅单标签数据集有意义
Macro-F1  = macro_f1(y_true=Y, y_pred=m)         # sklearn 口径，zero_division=0
```

- **reject 样本**：m=∅ → 该样本预测视为错误（F1 计入分母）。
- 多标签数据集（MixATIS/MixSNIPS）：主意图 = 数据集中标注的 main_intent；基线方法需说明如何从预测集合中选主意图（取最高分者），并在重算时统一为"集合内最高置信度意图"。

## 2. L1 集合指标（多意图核心，**全集合口径**）

```
Set Exact Match = #{ P == Y } / N
Set IoU         = mean( J(P, Y) )               # 逐样本 Jaccard 求平均
Hit@k           = #{ Y ⊆ top-k(R) } / N          # 真实全部意图被 R 前 k 位完全包含
Avg set size    = mean( |P| )
```

- **禁止拆分 aux 子集计算**（此前 Ours 的 Set Jaccard 曾在 aux 级上计算，必须改为 full 级：true = 全部意图，pred = 完整候选集）。
- reject 样本：P=∅ → Exact=0、IoU=0、Hit@k=0、set size 计入 0。
- Hit@k 需要各方法提供**排序输出 R**；无法提供排序的基线（如纯集合预测）可标注 N/A，但论文中不得用 N/A 代替 Hit@1（首选补算）。

## 3. L3 校准指标

```
Coverage(J≥0.5) = #{ J(P, Y) ≥ 0.5 } / N        # 集合级经验覆盖率，名义 1−α = 0.90
Coverage(含)    = #{ P ∩ Y ≠ ∅ } / N            # 辅助诊断指标（可选，多意图时建议并列报告）
ECE             = 15 bins，见下方统一规则
```

**ECE 统一规则（重要）**：
- 置信度口径：**主意图 top-1 置信度**（即"主意图预测正确的概率估计"）。
  - Ours：top1-fused confidence = 1 − min fused score；
  - CICC / MULACONF / QP：取各自模型对 top-1 类别的输出概率（softmax 或等价置信度）；
  - **各方法必须注明置信度来源**，论文表格脚注统一说明。
- correct 定义：主意图预测正确（m == 唯一真实意图 / main_intent）。
- reject 样本：置信度记为该样本被判拒时的置信度（阈值下界），correct=0。

## 4. L5 决策指标

```
误拒率 (in-domain)     = #{ x ∈ D_in : P = ∅ } / |D_in|
OOS 拒识率             = #{ x ∈ D_oos : P = ∅ } / |D_oos|      # 仅 CLINC150；多标签数据集标注 N/A
澄清触发率             = #{ 决策为 clarify } / N
拒识率@95% OOS 召回     = 标定阈值使 OOS 拒识率 = 95%，报告此时的 in-domain 误拒率   # 仅 CLINC150
```

- **误拒率唯一合法定义**：in-domain 样本中被系统判为"拒绝/空集"的比例。**禁止**用"集合与标签无交集比例"替代（无交集是 Coverage 的反面，不是决策行为）。
- MULACONF 此前报的 MixATIS 误拒率=1.0、MixSNIPS=0.819 与 Coverage(J≥0.5)=0.936~0.997 自相矛盾，**必须核实其"误拒率"的真实计算方式并改用本规范重算**。
- 澄清触发率：Ours 为三态决策 clarify；CICC/MULACONF 若机制不同（如"澄清轮次"），需注明其判定规则，或统一不报该指标。

## 5. 各方法重算/澄清清单

| 方法 | 必改项 |
|---|---|
| **Ours** | ① Set Exact Match / Set Jaccard 改为 full 级（true=全部意图，pred=完整候选集 pred_full）；② 补算 Hit@1/3/5（用 fused 排序）；③ Coverage(J≥0.5) 已同口径（MixSNIPS=0.136，重报时注明）；④ ECE 已按 top1-fused，保持 |
| **CICC (R5)** | ① 明确其"预测集合"如何由 CP 输出（avg set size=78.7 的集合构成）；② 按 full 级重算 Exact/IoU/Hit@k；③ ECE 置信度来源注明；④ 误拒率按"拒绝/空集"口径重算 |
| **MULACONF (R12)** | ① **澄清 MixATIS 误拒率=1.0、MixSNIPS Powerset=0.819 的原始定义**，按本规范重算；② IoU 计算对象：必须含被拒样本（P=∅ 计 0），禁止只在非拒子集上平均；③ Tree fixed α 的集合产出方式说明；④ ECE 置信度来源注明 |
| **QP-OneModel (R12 变体)** | ① set size 固定 5 的说明保留，但 Exact/IoU/Hit@k 按 full 级重算；② ECE 置信度来源注明；③ 1/5/10-shot 均按本规范 |

## 6. 数据口径（α 与重复实验）

- 统一 α = 0.1（名义覆盖率 1−α = 0.90），split conformal。
- 统一报告 3 次重复实验的"均值 ± 标准差"（Ours 目前单次，如时间允许补 3 次；至少注明单次）。
- MixSNIPS / MixATIS 无 OOS 类：OOS 指标列写 N/A，不写 0。
