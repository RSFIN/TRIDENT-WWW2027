查询天然模糊——同一查询可对应多个意图，用户常在一条输入里提出多项需求，长尾查询缺少上下文。公开证据显示这是系统性缺口：TREC CAsT 已把\"歧义识别＋澄清问题选择\"单列为评测任务<a href=\"https://trec.nist.gov/data/cast2022.html\">[15]</a>；Needle in the Web 的 663 条模糊探索式查询上，多数 Agent 准确率低于 35%<a href=\"https://arxiv.org/abs/2512.16553\">[16]</a>；VibeSearchBench 中最佳模型 F1 仅 30.30<a href=\"https://arxiv.org/abs/2605.27882\">[8]</a>。在必须单轮响应的入口（搜索框、IM 机器人、Agent 冷启动），系统必须一次给出\"有序意图集\"，并对不确定输入做出可信决策。</p><p id=\"doxcnnpQU78wM8RxXQx93pOsGZd\"><b>差距：</b>现有三类方法都未同时覆盖单轮多意图与可信拒识。Prism 依赖多轮澄清与自演进微调，不适配没有澄清机会的单轮入口<a href=\"https://arxiv.org/abs/2601.08653\">[6]</a>；DoorDash 借助电商目录实体与商品检索做 grounding，不面向通用查询<a href=\"https://arxiv.org/abs/2603.01486\">[7]</a>；QP-OneModel 用统一生成式输出意图描述，但未给出可保证的拒识/澄清触发决策<a href=\"https://arxiv.org/abs/2602.09901\">[12]</a>。与此同时，意图理解的\"可信度\"维度（OOS 拒识、置信度校准、误拒成本）在 Web 场景缺少系统研究——OOS 检测的 hard-negative 脆弱性已被反复证实（Banking77 上 AUROC 由 0.964 降至 0.810）<a href=\"https://arxiv.org/abs/2403.05640\">[20]</a><a href=\"https://arxiv.org/abs/2101.03778\">[21]</a><a href=\"https://xdbdilab.feishu.cn/docx/Xg9MdxNOFoAhQWxiAjnc1wEynXd\">[17]</a>。</p><p id=\"doxcn0WkjSwUz47vxOjROY3r0Yc\"><b>定位与贡献：</b>我们提出面向 Web 查询入口的单轮意图理解框架：免训练知识库索引＋检索增强推理输出\"主意图＋有序次意图集\"，校准模块提供可靠不确定性，三态决策决定放行、澄清还是拒识。三条贡献：(1) 首个将\"多意图集输出\"与\"校准拒识\"一体化的单轮框架，与上述三点差异化；(2) 全公开数据的三组评测协议与 L1–L6 指标子集，可直接复现；(3) 算法贡献：检索-grounded 无分类器集合级共形校准——把共形从\"单点/固定标签集覆盖\"扩展到\"变长多意图集 Jaccard 覆盖\"，配合自适应最小澄清集；(4) 工程证据：免训练路线在\"零训练部署×知识可更新×精度×校准\"上的表现，轻微调（LoRA/SetFit）对照量化轻量训练增益。</p><h1 CLINC150（150 意图/10 域、含原生 OOS）、Banking77、HWU64 仍是评测事实标准<a href=\"https://xdbdilab.feishu.cn/docx/Xg9MdxNOFoAhQWxiAjnc1wEynXd\">[17]</a>。2025–2026 年新基准把难度推高：IntentGrasp 将意图理解统一为多选问答，20 个前沿模型在高难度 Gem Set 上 F1 全部低于 25%、17/20 低于随机基线（15.2%），人类基线 81.1%<a href=\"https://arxiv.org/html/2605.06832v1\">[10]</a>；ConsintBench 在 20 万+ 条真实消费讨论上评测 20 个模型，最强模型在深层意图理解上仍不足<a href=\"https://arxiv.org/html/2510.13499v2\">[11]</a>。结论：意图理解远未饱和，评测正从\"分得准\"走向\"理解深、拒得对\"。本文承接该趋势，把\"多意图集＋拒识\"作为可评测的能力维度。</p><h2 id=\"doxcneygIg5S43kWNdMNmfaXMUd\">多意图与组合意图理解</h2><p id=\"doxcnaYrntd0nYZZOD4tgHKLEhg\">MixATIS/MixSNIPS 首次把 ATIS/SNIPS 拼出 1–3 意图混合查询（比例约 3:5:2）<a href=\"https://github.com/LooperXX/AGIF\">[13]</a>；MultiSNIPS 等进一步建模意图共现关系<a href=\"https://arxiv.org/html/2602.08322v2\">[14]</a>；生成式多意图检测把任务建模为多标签输出。本文差异：现有工作聚焦\"预测得准\"，本文把多意图集输出与\"校准后的拒识决策\"绑定，除 Hit@k/意图集 IoU 外还评测\"何时该拒\"。</p><h2 id=\"doxcnxJfvYtbrrQOQnrX0GMnCyb\">OOS 检测与不确定性校准</h2><p id=\"doxcn93dp6T6qd5KZV9eUHVmGBc\">判别式 OOS 强基线仍是 Mahalanobis 距离（CLINC150 上 AUROC 98.4、FPR95 6.8）<a href=\"https://arxiv.org/abs/2101.03778\">[21]</a>；DROID 双表示在 CLINC150 上 Unknown 95.88%<a href=\"https://arxiv.org/html/2510.14110v1\">[19]</a>；但 hard-negative OOS 使 AUROC 显著下降<a href=\"https://arxiv.org/abs/2403.05640\">[20]</a>，多党派对话场景 F1-OOS 仅 45.00 且人类基线仍更高<a href=\"https://arxiv.org/html/2507.22289v1\">[22]</a>。校准方向，温度缩放与共形预测可提供带覆盖保证的候选集<a href=\"https://xdbdilab.feishu.cn/docx/Xg9MdxNOFoAhQWxiAjnc1wEynXd\">[17]</a>。本文差异：把校准与拒识接入三态决策，并在公开模糊查询源上评测\"拒识→澄清触发\"的决策质量。</p><p id=\"doxcnv8AytWrHtlg3WnGNUtabxh\"><b>共形预测与 LLM 不确定性校准的最新进展。</b>共形预测（CP）近年从判别式分类器快速扩展到黑盒 LLM。CICC <a href=\"https://arxiv.org/abs/2403.18973\">[31]</a> 最早把 CP 用于意图识别，在 BERT 分类器上构造带覆盖保证的澄清集并扩展到 OOS，但它绑定判别式 backbone，不处理 LLM-native 场景。UniCR <a href=\"https://arxiv.org/abs/2509.01455\">[34]</a> 融合 self-consistency、retrieval compatibility 等多源证据，用 conformal risk control 做 API-only LLM 的拒答，但面向长文本生成、输出单标签拒绝，不做意图集合扩展。TECP <a href=\"https://arxiv.org/abs/2509.00461\">[35]</a> 用 token entropy 作 logit-free nonconformity score 构造预测集，同样面向选择题 QA。MiRD <a href=\"https://arxiv.org/abs/2605.27091\">[36]</a> 在开放域 QA 上做 miscoverage risk decomposition，把错误分解为漏答/错答两类——这与本文四档分层 loss 思想相通，但 MiRD 不处理意图主辅层级。Xie et al. <a href=\"https://yanfeifionazhou.github.io/\">[37]</a> 针对开放集+不平衡分类提出 CP 框架；Learnable Conformal Abstention <a href=\"https://arxiv.org/abs/2502.06884\">[38]</a> 用 RL 动态学阈值。CP for NLP 综述见 <a href=\"https://arxiv.org/abs/2405.01976\">[39]</a>。</p><p id=\"doxcnkSIC7dWKsF4ooX6vtsuo0g\"><b>本文定位。</b>现有工作要么绑定判别式 backbone（CICC、Mahalanobis、DROID），要么面向单标签选择或长文本 QA（UniCR、TECP、MiRD）。本文是第一个把 <b>stratified set-valued conformal</b> 用于 <b>LLM-native 多意图识别 + dual OOS 拒识</b> 的工作：四档分层 loss 显式区分 main/aux 覆盖，rank 归一化融合检索分与 LLM 置信度，offline split CP 提供 finite-sample coverage 保证。</p><h2 id=\"doxcnoKijP6KYwkHvTYUpqqyUDe\">免训练与高效意图分类</h2><p id=\"doxcnMO06S8BGox3swmUu0GEgPg\">41 个开源权重模型的系统评测显示指令微调优先于参数规模（Qwen2.5-3B-Instruct 聚合得分 0.632 超过多数 7B 基础模型），SNIPS 已饱和、校准影响不一致<a href=\"https://arxiv.org/html/2607.27421v1\">[18]</a>；混合路由（小模型＋不确定性→LLM）是工业事实标准，可在接近大模型精度下显著降低延迟<a href=\"https://xdbdilab.feishu.cn/docx/Xg9MdxNOFoAhQWxiAjnc1wEynXd\">[17]</a>。在此基础上，检索增强意图分类（REIC）验证了免重训优势[24]，检索式 kNN 分类在低资源语言有效[26]，嵌入近邻是零样本文本分类标准路线[27]。本文据此选\"免训练知识库索引＋检索增强推理＋校准拒识\"为方法主干，纯 LLM、混合路由与轻量微调（LoRA/SetFit）作对照。</p><h2 id=\"doxcnzczsO1EsqhA8Ii0xVJb3yd\">Web 场景的意图理解</h2><p id=\"doxcncpiqfRDEyf03naXtMOPEgh\">Prism 用复杂意图分解＋逻辑澄清序列降低用户认知负荷<a href=\"https://arxiv.org/abs/2601.08653\">[6]</a>；DoorDash 用目录实体检索＋agentic 搜索＋有序多意图集服务长尾查询（长尾 query 90.7%，相对提升 13.0pp）<a href=\"https://arxiv.org/abs/2603.01486\">[7]</a>；QP-OneModel 统一生成式查询理解<a href=\"https://arxiv.org/abs/2602.09901\">[12]</a>；INTENT-AS-A-TOOL 从 Agent 安全侧追踪意图信号<a href=\"https://arxiv.org/abs/2608.27348\">[9]</a>。本文差异：不依赖多轮、不依赖垂直目录，面向通用单轮入口，把\"有序意图集＋可信拒识\"作为产品可落地的最小闭环。</p><h1 id=\"doxcnKVLkJMkVJfYDDgfuTmJJmf\">方法（形式化定义）</h1><p id=\"doxcndmeCDafHsNWHLSivdEznzd\">问题定义：给定查询 q 与意图空间 I（取自公开数据集的意图标签集），系统输出主意图 ŷ∈I、有序次意图集 Ŝ＝{ŷ₂,…,ŷ_K}，以及不确定性 u；三态决策按阈值 (τ_lo, τ_hi) 决定：u≥τ_hi 放行，τ_lo≤u&lt;τ_hi 触发澄清（返回候选意图集供用户确认），u&lt;τ_lo 拒识（转人工/安全兜底）。与单标签歧义任务不同，此处真实输出本身是变长意图集 Y（一个查询可同时成立多个意图），因此\"覆盖\"的对象不是某个固定标签，而是 Y 与预测意图集 Ŝ 的集合相似度（Jaccard / 对称差）。免训练设定下不存在可输出 logits 的分类器，不确定性由检索证据与 LLM 自评共同构造。</p><p id=\"doxcnbua4spAJYeSqcUW5s98wwg\">模块一 意图知识库构建与检索增强推理：知识库＝公开数据集 train 的意图定义＋示例话语（零标注），索引＝意图级原型＋示例级向量；检索 Top-K（K_r 超参）候选送入 LLM 证据上下文，输出\"主意图＋有序次意图集\"；K 与 K_r 均作超参消融。</p><p id=\"doxcnR6ll6DYQ5r9vvp1TDwQdFh\">模块二（核心贡献 A：检索-grounded 无分类器集合级共形校准）：现有共形意图方法（如 CICC）假设有训练好的分类器输出分数，免训练路线只有检索相似度与 LLM 自报置信，两者均不可靠且相关。本模块构造融合非一致性分数 s(q)＝g(检索分布统计量 [Top-K 相似度、Top1−Top2 margin、与已确认条目距离], LLM 自评)，在校准集上做 split-conformal；风险度量取预测意图集 Ŝ 与真实意图集 Y 的 Jaccard，控制\"集合级错误率\"（对称差超过阈值的概率）在 1−α 以内。这是把共形从\"单点覆盖\"扩展到\"变长意图集集合级覆盖\"，无需任何梯度训练。</p><p id=\"doxcnTpTEW1FP6myfysGCeIyXWf\">模块三（核心贡献 B：自适应澄清集大小）：澄清不再返回固定 K 个候选，而是在模块二的共形保证下取最小集合——保证 Ŝ 以 ≥1−α 概率覆盖真实意图集 Y 的最小候选意图数。模糊/长尾查询返回 2–3 个候选，明确查询返回 1 个，域外查询返回 0 个（直接拒识）。三态阈值 (τ_lo, τ_hi) 在校准集上按 FPR95 约束下最大化拒识召回标定；拒识保留安全兜底语义。三个模块可独立消融，对应第 5.5 节。</p><p id=\"doxcnYAwdz4Nu0Y8J5NZgCxtMce\">方法框架如图 1 所示：知识库构建/检索与推理侧解耦——知识库零标注构建、检索与 LLM 推理免训练，轻微调（LoRA/SetFit）仅作对照。与 CICC（单标签、有训练分类器、TODS 场景）的关键差异在模块二/三：无分类器分数、变长多意图集、Web 单轮拒识。模块与消融一一对应。</p><img id=\"doxcn5aQKTSaap2rtbtJVSvkaVg\" name=\"fig1_main_preview.png\" caption=\"Figure 1: Overview of the proposed training-free framework. id=\"doxcnnx0bjNB4XNM3EpXlftwhbE\">结合实际实验路径（免训练为主，无 GPU 训练条件），基线按\"是否做共形校准\"组织，而非\"LLM vs 判别式\"。核心论点：零训练 LLM 已能做意图识别但 overconfident，本文贡献是给它加上带 coverage 保证的集合级校准与拒识。R1–R5 全部直接复用已有 predictions（无需再调 LLM API）；R6–R8 为消融，改 config/重跑 calib 阈值即可。</p><p id=\"doxcnpSHSkVkT2Ymr5zJ6x2eTTh\"><b>主参数定稿（2026-09-30，经 P3 消融定稿）：</b>检索候选 K_r 固定为 5（top-5 召回），评估时截断使用 top-1（k_r_use=1）；澄清集最大大小 K=1；融合权重 fusion_alpha=0.1；tau_aux=0.5；α=0.1（split conformal）。定稿依据见「消融计划 → P3 消融执行结果」：K=1 与 K_r=1 在多意图数据集上均为联合最优（集合质量与紧致性最优、Cov 保持），CLINC150 单意图下 K/K_r 无影响，故全表统一采用该配置，消除跨数据集超参差异的质疑。</p><h3 id=\"doxcnZh3IScr05b0rFstO4ATnUf\">Plan-Extra：低参数量模型上的鲁棒性验证</h3><p id=\"doxcnIeyTeAUpJcGJucYcFnPlrc\"><b>实验设置：</b>用 DashScope 上的 Qwen2.5-7B-Instruct（或 Llama-3.1-8B）替换 qwen3.7-plus，保持相同 prompt、相同检索索引、相同共形 pipeline，在 CLINC150 上重跑 calib+test。预期 Main Macro-F1 从 0.899 降到 ~0.75-0.80。</p><p id=\"doxcnRXpX9inMmJbH8SUqONglMf\"><b>这个实验对论文的意义（写论文时必须讲清楚）：</b></p><ol><li id=\"doxcnUwwuXKjE2urnqsVSoa1vYQ\" seq=\"1\" seq-marker=\"1. \"><b>证明 coverage guarantee 是模型无关的。</b>共形预测的有限样本覆盖保证来自 exchangeability，不依赖 f_LLM 的准确率。无论 backbone 是 70B API 还是 7B 本地模型，calib 集上分位数取到的阈值都保证 test 集 coverage ≥ 1-α。这是我们方法的理论卖点——它把\"模型能力差异\"转化为\"预测集大小/拒识率差异\"，而不是破坏覆盖保证。</li><li id=\"doxcnNms5ifyd8Y7gqo7kJHBfBh\" seq-marker=\"2. \"><b>展示 error-coverage tradeoff 曲线的形态。</b>小模型 baseline accuracy 低，共形校准会自动输出更大的候选集、更多 clarify/reject 决策，但 coverage 仍然达标。这张图（横轴 alpha，纵轴 empirical coverage，多条曲线对应不同模型规模）直接回应审稿人\"你是不是只在强模型上 cherry-pick\"的质疑。</li><li id=\"doxcnC0Aqg511rDCyqh32jq8epg\" seq-marker=\"3. \"><b>工程落地价值。</b>很多真实场景不能调用商用大模型 API（数据隐私、延迟、成本），必须本地部署 7B。我们的方法在小模型上仍然提供 finite-sample 统计保证，这把论文的适用范围从\"云端大模型\"扩展到\"边缘本地模型\"，是 WWW 审稿人看重的 deployment story。</li><li id=\"doxcn0ctlDGGZUkKry2S6INDAPb\" seq-marker=\"4. \"><b>与 R13（SetFit 混合路由）形成呼应。</b>小模型实验 + 混合路由实验一起回答：\"为什么不直接用小模型+混合路由？\"答案是：小模型+混合路由省了 API 调用但没有 coverage guarantee；我们的方法即使在 7B 上仍然有统计保证。</li></ol><p id=\"doxcnSxHoWRW9GTaMwxjWJgCHnb\"><b>时间点：</b>主表（CLINC150/MixATIS/MixSNIPS + R9/R10/R12）出来后再跑，不阻塞投稿。若算力紧张，只在 CLINC150 上做一个 7B 点即可。</p><h3 id=\"doxcnv4qIiafsZLENVxcbLTwbBe\">子任务 R11：TECP-style Token Entropy 共形（参考论文 + 实现）</h3><p id=\"doxcnFzW1xqbrj5TjsnBgfE2pKg\"><b>参考论文：</b>TECP: Token-Entropy Conformal Prediction for LLMs（arXiv 2509.00461）。核心思想：对同一 query 用 temperature&gt;0 采样 LLM T 次，统计 main intent 的预测分布熵作为 epistemic uncertainty，再做 split conformal。</p><p id=\"doxcnSt9N6DSAp7jTMeumgwIc6e\"><b>具体步骤：</b></p><ol><li id=\"doxcnsZnZHwc1E0MPK08BN3H365\" seq=\"1\" seq-marker=\"1. \">新建 <code>scripts/11_run_llm_samples.py</code>，基于现有 <code>03_run_llm.py</code>，把 <code>llm.classify_intent()</code> 调用包成循环：temperature=0.7，采样 T=5 次，输出 5 个 llm_main 列表。</li><li id=\"doxcn1Zj2ww1QembFjjocWDpBjf\" seq-marker=\"2. \">先在 CLINC150 test 上跑 500 条子样本（<code>--limit 500</code>），确认 API 配额够用。输出格式：每条 record 加字段 <code>\"samples\": [\"intent1\",\"intent2\",...]</code>。</li><li id=\"doxcnQtJTTGcMvUE26lktl1PUwc\" seq-marker=\"3. \">新建 <code>scripts/11_eval_tecp.py</code>：对每条样本，统计 5 次采样中 main intent 的频率分布 p(y)，算 entropy <code>H = -Σ p(y) log p(y)</code>；calib 集上取分位数作为阈值 θ；test 集上 entropy &gt; θ 则 reject，否则取 argmax。</li><li id=\"doxcnp72r4mvQTlNceGpU0LC7le\" seq-marker=\"4. \">对比指标：和我们的方法在同一 test 子集上比 (a) Main Macro-F1，(b) OOS AUROC，(c) avg 调用成本（5× vs 1×），(d) coverage at α=0.1。</li></ol><p id=\"doxcnloxOnQcrYlRO7nPeDI85oe\"><b>预期结论：</b>TECP 的 entropy 准确率可能略高，但 5× API 成本；我们单次调用 + 检索融合在 coverage 相当的情况下成本 1/5。这张 cost-accuracy tradeoff 图放论文 Figure 4。</p><p id=\"doxcn8mJLu1z4OtSkjl7fUIIeig\"><b>时间估计：</b>脚本 0.5 天，500 条采样 ~2 小时跑通，3 天出结果。</p><h3 id=\"doxcnuzKJLYrRP3zoDuocMjrjkg\">子任务 R13：SetFit + MC Dropout 混合路由（参考论文 + 实现）</h3><p id=\"doxcnZ2CR1wm5Z3Ap8UbFv27zRc\"><b>参考论文：</b>\"Intent Detection in the Age of LLMs\"（arXiv 2410.01627）——用 BGE sentence transformer + 0.1 dropout 做 MC sampling；<b>开源库：</b><code>pip install setfit open-autonlu</code>（open-autonlu 内置 SetFit + MSP/Mahalanobis OOD detection）。</p><p id=\"doxcnkvBD9TjSyRdheEJsmibDTg\"><b>具体步骤：</b></p><ol><li id=\"doxcnj9bxT41NVx7kSh4MkJnF1d\" seq=\"1\" seq-marker=\"1. \">环境：<code>pip install setfit open-autonlu datasets</code>，不需要 GPU（CPU 即可，SetFit few-shot 训练很快）。</li><li id=\"doxcnrhzJA3R443ctQJgQpu4HIe\" seq-marker=\"2. \">数据：用现有 <code>data/processed/{clinc150,mixatis}/train.jsonl</code>，每类随机抽 16 例做 few-shot train（CLINC150 135 类 × 16 = 2160 条，MixATIS 17 类 × 16 = 272 条）。</li><li id=\"doxcn68dJs76vCHgm8gTRhOZjJf\" seq-marker=\"3. \">训练：<code>SetFitModel.from_pretrained(\"BAAI/bge-small-en-v1.5\")</code>，用 sklearn LogisticRegression 做 classification head，1 epoch 对比学习训练。参考 HuggingFace 官方 notebook <code>setfit_doc/en/zero_shot.ipynb</code>。</li><li id=\"doxcnHbqNAoAKGjJtikIevMqyOg\" seq-marker=\"4. \">MC Dropout 推理：把 model 设为 <code>model.model_body.eval()</code> 但打开 dropout（<code>for m in model.modules(): if isinstance(m, nn.Dropout): m.train()</code>），对每条 test 样本前向 T=30 次，收集 30 个预测分布，算 predictive entropy 和 mutual information。</li><li id=\"doxcnJOeSNFkTClwEFlSdq57mPe\" seq-marker=\"5. \">OOS 检测：用 open-autonlu 的 <code>OodMethod.MSP_OOD</code> 或 Mahalanobis 距离，在 calib 集上定 FPR=0.05 阈值。</li><li id=\"doxcnBAWfN7kwFVArLIZ3OtU4ag\" seq-marker=\"6. \">混合路由决策：entropy 小于阈值 tau 时直接用 SetFit 结果（省 LLM）；entropy 大于等于 tau 或 OOS 时 fallback 到我们的 LLM + 共形校准。统计 LLM 调用率（fallback 比例）和整体准确率。</li></ol><p id=\"doxcnEnvZ40wsG6Ft421KlEuMih\"><b>对比指标：</b>(a) 端到端 Main F1，(b) LLM API 调用比例（越低越好），(c) OOS AUROC，(d) 是否有 coverage guarantee（我们有，混合路由没有——这是核心论点）。</p><p id=\"doxcnIF4GW3PnPoTEeQRjqNQr4g\"><b>时间估计：</b>环境搭建 0.5 天，训练+MC 推理 1 天，调通 OOS 和 fallback 逻辑 1 天，3 天出结果。</p><p Entry points that must respond in a single turn—search boxes, instant-messaging assistants, and agent cold starts—therefore need to output an <em>ordered set of intents</em> and, crucially, to decide <em>when to release, clarify, or refuse</em>. Yet existing approaches either rely on multi-turn clarification [6], require vertical-domain grounding [7], or emit generative descriptions without any calibrated refusal guarantee [12].</p><p id=\"doxcnwEkaBEuBtUQehuRtAPR20f\">We propose a training-free framework for single-turn intent understanding that couples multi-intent set output with calibrated refusal. Our method (i) builds a zero-annotation intent knowledge base and applies retrieval-augmented inference to produce a primary intent plus an ordered set of secondary intents; (ii) introduces retrieval-grounded, classifier-free set-valued conformal calibration, which extends conformal prediction from point / fixed-label-set coverage to variable-length multi-intent <latex>Jaccard</latex> coverage by fusing retrieval statistics with LLM self-assessment—no gradient training is required; and (iii) derives an adaptive minimal clarification set, returning 1 candidate for clear queries, 2–3 for ambiguous ones, and an empty set (refusal) for out-of-scope input.</p><p id=\"doxcniAor2AIIzIXkl3y5SFOcsg\">On CLINC150, MixATIS, and MixSNIPS (two independent runs, <latex>\\alpha=0.1</latex>), the method achieves 100% out-of-scope refusal, expected calibration error as low as 0.005, and tight sets (avg size 0.87 / 1.52 / 1.80) while maintaining the nominal coverage guarantee. It dominates conformal baselines (CICC [31], MULACONF [33], TECP-style [35], UniCR [34]) and the generative set baseline (QP-OneModel [12]) in set compactness and calibration, and under an equal-risk operating point closes the F1 gap to few-shot LLM baselines to ~2.7pt while preserving finite-sample guarantees those baselines do not provide [P0-1].</p><h2 id=\"doxcndY3hckQBHVH1HBV3fzc0zd\">1. Introduction</h2><p id=\"doxcnpQpe5S0k1RRJ2eE7V3sUPd\"><b>1.1 The problem.</b> Web queries are inherently ambiguous and composite. The same query can map to multiple intents; users routinely pack several requests into one input; and long-tail queries arrive with little context. Public evidence shows this is a systematic, unsolved gap: TREC CAsT has made ambiguity identification and clarification-question selection a standalone task [15]; on the 663 ambiguous exploratory queries of Needle in the Web, most agents score below 35% accuracy [16]; and the best model on VibeSearchBench reaches only F1 30.30 [8]. Entry points that must respond in a single turn—search boxes, IM assistants, and agent cold starts—have no chance to re-ask. They must return an <em>ordered set of intents</em> in one response and, just as importantly, make a <em>trustworthy decision</em> about whether to release, clarify, or refuse.</p><p id=\"doxcnydNUup7sIn3yVcPYiPfpgb\"><b>1.2 The gap.</b> Existing approaches cover only part of this requirement. Prism [6] decomposes complex intents and drives clarification through an evolving dialogue, but it depends on multi-turn interaction and self-evolving fine-tuning—unavailable in single-turn entries. DoorDash's agentic grounding [7] is effective in its vertical (catalog entities, 90.7% long-tail coverage) but does not generalize to open-web queries. QP-OneModel [12] unifies query understanding under a generative decoder but provides no guaranteed refusal or clarification trigger. Meanwhile, the <em>trustworthiness</em> dimension of intent understanding—out-of-scope (OOS) refusal, confidence calibration, and the cost of false refusal—is under-studied in the Web setting: OOS detectors are notoriously fragile to hard negatives (AUROC drops from 0.964 to 0.810 on Banking77 [20][21]), and calibrated decision-making for open-set intents remains largely unaddressed.</p><p id=\"doxcnG1qPcqhiu0IzyFApT9zIEb\"><b>1.3 Our approach and contributions.</b> We propose a training-free framework for single-turn intent understanding that couples multi-intent set output with calibrated refusal. The pipeline is retrieval-grounded: a zero-annotation intent knowledge base (definitions + example utterances, no human labels) is indexed into intent-level prototypes and utterance-level vectors; retrieval-augmented inference feeds the top-K candidates into an LLM, which outputs a primary intent and an ordered set of secondary intents. A calibration module—the core of our method—constructs a fused nonconformity score from retrieval statistics and LLM self-assessment, and performs split conformal calibration on a set-level risk (Jaccard similarity between the predicted set and the true intent set), extending conformal prediction from single-point / fixed-label-set coverage to variable-length multi-intent set coverage without any gradient training. A three-state decision module then returns an adaptive minimal clarification set: 1 candidate for clear queries, 2–3 for ambiguous ones, and 0 (refusal) for out-of-scope input.</p><p id=\"doxcngik73aL0PXETQ2maM8gFTh\">Our contributions are four-fold: (1) we present, to our knowledge, the first single-turn framework that unifies multi-intent set output with calibrated refusal, differentiated from multi-turn clarification [6], vertical grounding [7], and guarantee-free generation [12]; (2) we introduce retrieval-grounded, classifier-free set-valued conformal calibration, extending conformal prediction from point / fixed-label coverage to variable-length multi-intent Jaccard coverage; (3) we contribute an adaptive minimal clarification set with three-state decision, calibrated on the validation set under an FPR95 constraint; and (4) we provide an engineering study showing that the training-free route—zero-training deployment, knowledge updatability, accuracy, and calibration—is competitive, with light fine-tuning (LoRA/SetFit) as controlled comparison.</p><p id=\"doxcnKzE8ND48me61trbjYI0QG9\"><b>1.4 Results and organization.</b> On CLINC150, MixATIS, and MixSNIPS with two independent runs at α=0.1, our method achieves 100% OOS refusal (CLINC150), ECE 0.005/0.219/0.045, and tight sets (avg 0.87/1.52/1.80). It outperforms conformal baselines (CICC, MULACONF, UniCR) in set compactness and calibration, outperforms the TECP-style entropy baseline in cost (1× vs 5× LLM calls) with comparable calibration, and exceeds the generative QP-OneModel baseline in multi-intent set quality (T2b). Under an equal-risk operating point (P0-1), the F1 gap to the strongest few-shot LLM baseline shrinks to ~2.7pt while our ECE advantage is 6–8×, and the clarify-fair oracle analysis (P0-2) shows our multi-intent gap is largely a reporting-convention difference. Section 2 reviews related work; Section 3 formalizes the method; Section 4 details the experimental setup, results, and ablations; Section 5 concludes with limitations and future work.</p><h2 id=\"doxcntHlFxpxqw8OjTwgu2avPSe\">2. Related Work</h2><p id=\"doxcnReDS7panydSeWdsuybSVde\">Our work sits at the intersection of five lines: intent understanding benchmarks, multi-intent and compositional intent, OOS detection and calibration, training-free and efficient intent classification, and Web-scenario intent understanding. Table 3-1 in the design doc summarizes the positioning; below we detail the closest lines.</p><h3 id=\"doxcn08n82ICJQ6hm4Ox04TzLze\">2.1 Intent Understanding Benchmarks: From Label Classification to Deeper Capabilities</h3><p id=\"doxcnzjqnBMo8jP8cvNGZhoCjig\">Closed-set benchmarks—CLINC150 (150 intents / 10 domains with native OOS), Banking77, and HWU64—remain the de-facto testbeds [17]. Recent 2025–2026 benchmarks push difficulty further: IntentGrasp unifies intent understanding as multi-choice QA, where 20 frontier models all score below 25% F1 on the hard Gem Set (17/20 below the 15.2% random baseline) while the human baseline is 81.1% [10]; ConsintBench evaluates 20 models on 200k+ real consumer discussions and shows the strongest models still fall short on deep intent understanding [11]. The field is moving from \"classify accurately\" to \"understand deeply and refuse correctly.\" Our paper follows this trend and makes multi-intent sets plus refusal an evaluable capability dimension.</p><h3 id=\"doxcnRaEEbGU6e6otbh1sAxZfHb\">2.2 Multi-Intent and Compositional Intent</h3><p id=\"doxcnsqin1GGGLQsjCBrmBKNX3c\">MixATIS/MixSNIPS first synthesized 1–3-intent mixed queries from ATIS/SNIPS (roughly 3:5:2) [13]; MultiSNIPS further models intent co-occurrence [14]; generative multi-intent detection formulates the task as multi-label output [14]. Existing work focuses on \"predict accurately.\" We bind multi-intent set output to a calibrated refusal decision and, besides Hit@k and intent-set IoU, evaluate <em>when to refuse</em>.</p><h3 id=\"doxcnlO6R4DpxmXTlZv9r18Q9Xf\">2.3 OOS Detection and Uncertainty Calibration</h3><p id=\"doxcnS5is9HrXADv5kONW1xrkAb\">Discriminative OOS baselines remain strong: Mahalanobis distance (AUROC 98.4, FPR95 6.8 on CLINC150) [21]; DROID dual representation (95.88% Unknown on CLINC150) [19]. However, hard-negative OOS sharply degrades AUROC [20], and in multi-party dialogue the F1-OOS is only 45.00 with the human baseline still higher [22]. On the calibration side, temperature scaling and conformal prediction provide candidate sets with coverage guarantees [17]. Our difference: calibration and refusal are wired into a three-state decision and evaluated on decision quality over public ambiguous query sources.</p><p id=\"doxcna8XpIT0WArtPd7XFH5pLvd\"><b>Recent advances in conformal prediction and LLM uncertainty.</b> Conformal prediction (CP) has quickly spread from discriminative classifiers to black-box LLMs. CICC [31] first applied CP to intent classification, constructing calibrated clarification sets with coverage guarantees on a BERT classifier and extending them to OOS—but it is bound to a discriminative backbone and does not handle LLM-native pipelines. UniCR [34] fuses multi-source evidence (self-consistency, retrieval compatibility, etc.) under conformal risk control to enable API-only LLM refusal, yet targets long-form generation with single-label refusal and no intent-set expansion. TECP [35] uses token entropy as a logit-free nonconformity score for prediction sets, again on multi-choice QA. MiRD [36] performs miscoverage risk decomposition on open-domain QA, distinguishing missing vs. wrong answers—conceptually aligned with our stratified loss, but it does not handle primary/secondary intent hierarchy. Xie et al. [37] propose CP for open-set and imbalanced classification; Learnable Conformal Abstention [38] learns thresholds via RL; a survey of CP for NLP appears in [39].</p><p id=\"doxcnyUbQIjwoU1rK9A9amLZvbh\"><b>Our positioning.</b> Existing work either binds a discriminative backbone (CICC, Mahalanobis, DROID) or targets single-label choice / long-text QA (UniCR, TECP, MiRD). Ours is the first to apply <em>stratified set-valued conformal</em> to <em>LLM-native multi-intent recognition with dual OOS refusal</em>: a stratified loss explicitly separates main/aux coverage, rank-normalized fusion combines retrieval scores with LLM confidence, and offline split CP provides finite-sample coverage guarantees.</p><h3 id=\"doxcndjlZ2cZOtWp8AuQZyxuQxf\">2.4 Training-Free and Efficient Intent Classification</h3><p id=\"doxcnrxOUfSAYIFOfB9u5ps3RZb\">A systematic study of 41 open-weight models shows instruction fine-tuning dominates parameter scale (Qwen2.5-3B-Instruct aggregates 0.632, beating most 7B base models), SNIPS is saturated, and calibration effects are inconsistent [18]; hybrid routing (small model + uncertainty → LLM) is the industrial de-facto standard, approaching large-model accuracy at far lower latency [17]. Retrieval-augmented intent classification (REIC) demonstrates the no-retrain advantage [24]; retrieval-based kNN classification is effective in low-resource languages [26]; embedding neighbors are the standard zero-shot text classification route [27]. We therefore adopt a training-free knowledge-base index + retrieval-augmented reasoning + calibrated refusal as our method backbone, with pure-LLM, hybrid routing, and light fine-tuning (LoRA/SetFit) as comparisons.</p><h3 id=\"doxcnqHWgtfEN5np9qR3xAUdYzf\">2.5 Web-Scenario Intent Understanding</h3><p id=\"doxcn2ted7Pbqhr6j4aAq4hCMzb\">Prism lowers cognitive load via complex-intent decomposition and a logical clarification sequence [6]; DoorDash serves long-tail queries with catalog-entity retrieval + agentic search + ordered multi-intent sets (90.7% long-tail queries, +13.0pp relative) [7]; QP-OneModel unifies generative query understanding [12]; INTENT-AS-A-TOOL tracks intent signals from the agent-safety side [9]. We differ by not relying on multi-turn interaction or vertical catalogs: we target generic single-turn entries and treat the ordered intent set plus trusted refusal as the minimal deployable loop.</p><h2 id=\"doxcnYtLG242fcbSqrNMBBgxn6g\">3. Method</h2><p id=\"doxcnjTAEKtCYjqtpZov46CcgJd\"><b>3.1 Problem formulation.</b> Given a query <latex>q</latex> and an intent space <latex>\\mathcal{I}</latex> (from public datasets), the system outputs a primary intent <latex>\\hat{y}\\in\\mathcal{I}</latex>, an ordered set of secondary intents <latex>\\hat{S}=\\{\\hat{y}_2,\\dots,\\hat{y}_K\\}</latex>, and an uncertainty <latex>u</latex>. A three-state decision applies thresholds <latex>(\\tau_{lo},\\tau_{hi})</latex>: release if <latex>u\\ge\\tau_{hi}</latex>; clarify (return the candidate intent set for user confirmation) if <latex>\\tau_{lo}\\le u&lt;\\tau_{hi}</latex>; refuse (route to human / safe fallback) if <latex>u&lt;\\tau_{lo}</latex>. Unlike single-label ambiguity tasks, the ground truth here is itself a variable-length intent set <latex>Y</latex> (a query may satisfy multiple intents simultaneously); thus the object of coverage is not a fixed label but the set similarity between <latex>Y</latex> and the predicted set <latex>\\hat{S}</latex> (Jaccard / symmetric difference). Under the training-free setting there is no classifier emitting logits; uncertainty is constructed from retrieval evidence and LLM self-assessment.</p><p id=\"doxcn0kOEmD8aA9uz0H0aWueDgb\"><b>3.2 Module 1: Intent knowledge base and retrieval-augmented reasoning.</b> The knowledge base is built from the training splits of public datasets with <em>zero annotation</em>: intent definitions plus example utterances. The index contains intent-level prototypes and utterance-level vectors. Retrieval returns the top-<latex>K_r</latex> candidate intents (hyperparameter) as evidence context for the LLM, which outputs the primary intent plus the ordered secondary-intent set. Both <latex>K</latex> and <latex>K_r</latex> are ablated (Section 4.5).</p><p id=\"doxcnasxFcrouI2T8CjDSudXvbc\"><b>3.3 Module 2 (Contribution A): retrieval-grounded, classifier-free set-valued conformal calibration.</b> Existing conformal intent methods (e.g., CICC [31]) assume a trained classifier that emits scores; the training-free route only has retrieval similarities and LLM self-reported confidence, both unreliable and correlated. We construct a fused nonconformity score <latex>s(q)=g(\\text{retrieval statistics [top-}K_r\\text{ similarity, top1-top2 margin, distance to confirmed entries]}, \\text{LLM self-assessment})</latex>, and apply split conformal on a calibration set. The risk measure is the Jaccard similarity between the predicted set <latex>\\hat{S}</latex> and the true set <latex>Y</latex>, controlling the set-level error rate (probability that the symmetric difference exceeds a threshold) within <latex>1-\\alpha</latex>. This extends conformal prediction from single-point coverage to variable-length multi-intent set coverage, without any gradient training.</p><p id=\"doxcnt4sKfWjIoeZzWGo360EoPd\"><b>3.4 Module 3 (Contribution B): adaptive minimal clarification set.</b> Clarification no longer returns a fixed <latex>K</latex> candidates; instead, under the conformal guarantee of Module 2 it returns the minimal set that covers the true intent set <latex>Y</latex> with probability <latex>\\ge 1-\\alpha</latex>. Ambiguous / long-tail queries return 2–3 candidates, clear queries return 1, and out-of-scope queries return 0 (direct refusal). The three-state thresholds <latex>(\\tau_{lo},\\tau_{hi})</latex> are calibrated on the validation set to maximize refusal recall under an FPR95 constraint; refusal preserves the safe-fallback semantics. The three modules are independently ablatable, corresponding to Section 4.5. The overall framework is shown in Figure 1 (design doc): knowledge-base construction and retrieval are decoupled from reasoning—zero-annotation KB construction, training-free retrieval and LLM reasoning, with light fine-tuning (LoRA/SetFit) as control only. The key differences from CICC (single-label, trained classifier, TODS scenario) lie in Modules 2/3: classifier-free scores, variable-length multi-intent sets, and Web single-turn refusal.</p><h2 id=\"doxcnOaxAqeqXQlm17WyFgkFaub\">4. Experiments</h2><p id=\"doxcnANMWQxkG9Uk1Zzwi4pjbAb\"><b>4.1 Setup.</b> We evaluate on CLINC150 (150 in-scope intents, native OOS, ~5.5k test queries), MixATIS (~828 test queries, 1–3 intents), and MixSNIPS (~2,199 test queries, 1–3 intents), all public and unchanged. All methods are evaluated under a unified protocol v1.0: <latex>\\alpha=0.1</latex> split conformal; empty sets (refusal) counted in the full denominator; macro-F1 from sklearn macro (zero-division 0); ECE in 15 bins on the primary-intent top-1 confidence (Ours = 1 minus the minimal fused score); false-refusal rate = fraction of in-domain queries predicted as empty; OOS metrics on CLINC150 only; Hit@k over all true intents; the release / clarify / reject states are mutually exclusive. Two independent runs (seed42 / seed123) are averaged. Baselines: R10 UniCR [34], R5 CICC [31], R12 MULACONF [33], R12-QP QP-OneModel [12] (recomputed under v1.0, 3 seeds), R11 TECP-style token-entropy [35] (qwen3-8b/14b), R13 SetFit+MC-Dropout hybrid routing, and few-shot LLM baselines (Qwen3-8B/14B, DeepSeek-R1-Distill, 3/5/10-shot; appendix A).</p><p id=\"doxcny3nEcjhRCxcFsetGzF34ye\"><b>4.2 Main results.</b> Table T2a (CLINC150): Ours reaches F1 0.899 / IoU 0.856 / coverage(J≥0.5) 0.856 / avg set 0.87 / ECE 0.005 / false-refusal 0.139 / OOS refusal 1.000 / AUROC 0.978. It is the only method with 100% OOS refusal and near-perfect calibration, while staying within 0.6pt F1 of the strongest conformal baseline (R10, F1 0.905). Table T2b (MixATIS / MixSNIPS): Ours achieves IoU 0.387 / 0.757, Hit@3 0.239 / 0.619, avg set 1.52 / 1.80, ECE 0.219 / 0.045, clarify rates 0.728 / 0.839. Against multi-intent set baselines: MULACONF's sets are unusable on multi-intent data (avg set 150.6–748.5, false-refusal up to 1.0); QP-OneModel v1.0 remains below Ours even at 10-shot (IoU 0.299 / 0.460 vs. 0.387 / 0.757) while refusing nothing and triggering clarify on 97% of MixATIS queries (statistical trigger, not a risk decision); R11 TECP-style achieves comparable MixATIS IoU (0.368/0.384) but with ECE 0.471–0.566 and 5× LLM calls; R13 trades API cost (6.3–15.9% LLM call rate) but its set quality (IoU 0.190/0.302/0.475) and calibration (ECE 0.374–0.695) are far below Ours, with only 5.7% OOS refusal on CLINC150. Few-shot LLM baselines (Qwen3-14B 10-shot) lead in raw F1/IoU (0.956; 0.872 / 0.952) but provide no coverage guarantee, no OOS refusal, and no clarification interaction; their ECE is not computable under v1.0.</p><p id=\"doxcnWlltd9GX4eUnX4AlqCYROg\"><b>4.3 Risk-controlled comparison (P0).</b> P0-1 (equal-risk operating point, zero API): tightening the OOS gate from FPR 0.05 to 0.0005 raises Ours F1 0.899→0.929 and reduces false refusal 0.139→0.097 while keeping OOS refusal at 1.000 and ECE≤0.008—an equal-risk curve (Figure F11) shows Ours dominates QP and LLM few-shot in the calibrated region. P0-2 (clarify-fair oracle): under oracle clarification, Ours MixSNIPS IoU 0.754→0.942 (vs. 0.952 few-shot) and MixATIS 0.396→0.760 (vs. 0.872): the multi-intent gap is largely a reporting-convention difference, and Ours keeps tighter avg sets (1.52/1.80 vs. 2.15/2.01) for interaction control.</p><p id=\"doxcnVm5fiI6zlhkVKGvHUoLzAf\"><b>4.4 Efficiency and system-level comparison (R13).</b> R13 (SetFit + MC-Dropout routing, LLM fallback) is the industrial hybrid-routing baseline. It saves API cost (6.3–15.9% LLM call rate) but has no coverage guarantee and weak set ability (Section 4.2). Compared with Ours, the training-free route needs no labels, no GPU fine-tuning, and supports instant knowledge updates (A8, drift-before/after coverage gap remains controlled), at the cost of ~1.6–2.7% F1 vs. light fine-tuning controls (P3).</p><p id=\"doxcnqZgZCBdt4Dx7XfV8DDki0c\"><b>4.5 Ablations (P3).</b> (A1) K ablation (k_max∈{0,1,2,3}): K=1 is optimal for compactness/coverage trade-off. (A3) fusion alpha {0.0,1.0}: rank-normalized fusion with α=0.1 (retrieval-dominant with LLM auxiliary) is stable; pure retrieval (0.0) or pure LLM (1.0) both degrade calibration. (A5) K_r retrieval candidates {1,3,5}: K_r=1 suffices; more candidates add noise. (A9) cross-domain generalization: CLINC150-calibrated Ours transfers to MixSNIPS test with controlled coverage loss. (A4) set-level risk metric, (A2) temperature scaling comparison, (A8) knowledge-update simulation: all confirm the design choices. Main hyperparameters: K=1, K_r=1, fa=0.1, τ_aux=0.5. Light fine-tuning (LoRA) and KB example-count ablations are deferred (W4).</p><h2 id=\"doxcnYGvRDzf6z8cWQeq12SB0tb\">5. Conclusion and Future Work</h2><p id=\"doxcnI58vpG41WD8LqXDDuPL0af\">We presented a training-free, retrieval-grounded framework that unifies single-turn multi-intent set output with calibrated three-state refusal. On three public benchmarks, it is the only method combining finite-sample coverage guarantees, 100% OOS refusal, strong calibration, and tight sets, at zero training cost; its F1 gap to few-shot LLM baselines narrows to ~2.7pt under an equal-risk operating point. Limitations: MixATIS remains challenging (IoU 0.387, ECE 0.219); the LLM back-bone's self-assessment is still a proxy for logits; and web-scale long-tail generalization beyond public benchmarks is untested. Future work includes light-fine-tuning gains (LoRA/SetFit, W4), scaling to open-web queries (Needle in the Web / VibeSearchBench), and extending stratified set-valued conformal to multi-turn clarification with memory.</p><h1 id=\"doxcnSVGtvkgADi7ICoRggFESjc\">写作时间表（衔接 5 周排期）</h1><table id=\"doxcnyjIX5J5vlALJG9VA76VOSe\"><colgroup><col width=\"150\"/><col width=\"380\"/><col
